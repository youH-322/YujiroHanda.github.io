SCHOOL PROJECT

WORK 01

香川県観光紹介サイト

香川県の観光地や魅力を紹介することを目的に制作した複数ページのWebサイトです。 写真を大きく見せ、観光地の雰囲気が伝わる構成を意識しました。

制作区分
チーム制作（２名）
担当範囲
企画 / デザイン / コーディング / レスポンシブ対応
使用技術
HTML / CSS / JavaScript
主な実装
複数ページ / スライド表示 / 動画背景 / 内部・外部リンク

工夫した点

  • 画像を活用し、観光地の魅力が直感的に伝わるレイアウトにしました。
  • スマートフォンでも情報を追いやすいよう、画面幅に応じて配置を変更しました。
  • ナビゲーションとリンクの位置を統一し、ページ間を移動しやすくしました。
学生制作のため非公開 GitHub

WORK 02

ナイトレジャー関連サイト

知人からの紹介を通じて受注し、3名のチームで制作した実案件です。 業界特性と利用者層を考慮し、スマートフォンで目的の情報へ移動しやすい構成を意識しました。

制作区分
実案件 / チーム制作（3名）
担当範囲
フロントエンドコーディング / レスポンシブ調整 / プロジェクト管理
使用技術
HTML / CSS / JavaScript/TypeScript/WordPress
公開情報
守秘義務および掲載許可の都合により、サイト名・URLは非公開

工夫した点

  • 3名で担当箇所を分担し、共通のデザインルールを確認しながら制作しました。
  • スマートフォンからの閲覧を想定し、文字サイズやボタンの押しやすさを調整しました。
  • 実案件として、納期と修正内容を確認しながら最後まで責任を持って対応しました。
